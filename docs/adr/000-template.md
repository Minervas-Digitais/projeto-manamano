# Título

## Status

- **Proposta:** decisão que está sendo discutida e ainda não foi aprovada.
- **Aceita:** decisão aprovada e atualmente adotada.
- **Rejeitada:** decisão analisada, mas que não será adotada.
- **Obsoleta:** decisão que não deve mais ser utilizada, mas que pode ainda existir no sistema.
- **Substituída:** decisão que foi substituída por uma decisão mais recente.

**Status atual:** Proposta

## Contexto

## Decisão

Qual é a mudança que estamos propondo e/ou realizando?

## Alternativas consideradas (Opcional)

## Consequências
